# Privacy

MarkMyAss exists in two modes with genuinely different privacy
guarantees. Read this before uploading anything you consider sensitive.
MarkMyAss is powered by the GhostMark engine; the CLI command remains
`ghostmark`.

## Local MarkMyAss (CLI or `ghostmark ui` on your own computer)

**100% local. Nothing ever leaves your device.**

- No network calls of any kind. No telemetry, no analytics, no crash
  reporting, no update checks.
- The web UI binds to `127.0.0.1` only -- not reachable from other
  devices on your network.
- Files you inspect/clean are read, processed, and written entirely on
  your own filesystem.
- Temporary files (used internally during processing) live in your OS's
  temp directory and are cleaned up when the operation finishes.

This is the same guarantee MarkMyAss has always made, and it hasn't
changed.

## Hosted MarkMyAss (https://markmyass.com)

**This is different. Files ARE temporarily uploaded to a server.**

If you use the hosted version instead of running MarkMyAss locally:

- Uploaded files and pasted text are sent to, and temporarily processed
  on, the MarkMyAss server running at markmyass.com.
- Files are held only in a randomized, per-session temporary directory
  on that server -- never written to a database, never made
  permanent, and never included in application logs (server access
  logs record only the request path, e.g. `POST /api/inspect/file`, not
  the file's name or contents).
- A session's cleaned file and its downloadable Verification Receipt can
  be fetched separately, in either order, so nothing is deleted the
  instant you download one of them. Instead, the whole session
  (original + cleaned copy + receipt data) is deleted automatically
  after a short timeout -- 10-15 minutes maximum (see
  `GHOSTMARK_SESSION_TTL_MINUTES` in `docker-compose.prod.yml` for the
  exact current value).
- No accounts, no cookies used for tracking, no analytics, no
  advertising, no third-party trackers of any kind.
- The homepage's live activity counter works from anonymous, ephemeral,
  in-memory presence identifiers (a random ID generated by your browser
  tab) kept for a few minutes only, to display the aggregate active-user
  count. They are never persisted, never logged, and never used for
  tracking or advertising.
- No CORS is configured and the API is not intended for cross-origin use
  by other websites.

### Optional paid batch lot (only if enabled on the hosted site)

The hosted site may offer a paid "batch lot": a convenience shortcut to
clean 2 to 50 files in one go and download them as a ZIP. It changes
nothing about the free tool and is off unless explicitly enabled. If you
buy one:

- Payment is handled entirely by Stripe (we never see your card, and
  Stripe may send you its own receipt). The only thing we record is the
  Stripe Checkout Session id, a status and three timestamps (the Stripe
  payment date, when the lot was opened, when it was finalized) -- no
  e-mail, no name, no IP address, and never any file name, content or
  hash. No account is created and nothing is e-mailed by MarkMyAss.
- A paid lot must be processed and finalized within 24 hours of the
  Stripe payment (reopening the same confirmation link as often as
  needed); afterwards the payment is no longer usable.
- The files of a lot are processed exactly like free sessions, in a
  temporary directory that is deleted once the ZIP is built; the ZIP itself
  is deleted one hour after its creation at the latest, and intermediate
  results after one hour as well.

If you would rather not upload anything anywhere, use local MarkMyAss
instead -- see the README's "Run MarkMyAss locally" section. Both modes
run the exact same open-source code
(https://github.com/bens777/MarkMyAss); the only difference is where the
processing happens.

## What MarkMyAss never does, in either mode

- Never sells or shares data with third parties (there is nothing
  collected to share).
- Never uses uploaded content to train any model.
- Never requires an account, password or email address. Cleaning files
  one at a time never requires a payment either; only the optional paid
  batch lot above involves a payment, handled by Stripe.
- Never adds tracking pixels, fingerprinting scripts, or ad networks.

## Independent verification (ExifTool + c2patool)

When available, MarkMyAss shells out to a locally/server-installed copy
of [ExifTool](https://exiftool.org/) and/or
[c2patool](https://github.com/contentauth/c2pa-rs) to independently
cross-check a cleaned file. This happens entirely within the same
process/server that already has the file -- neither tool is a network
service, and no data is sent anywhere by using them.
